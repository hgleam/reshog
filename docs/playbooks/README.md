# playbooks（手順・理由・事例・表の置き場）

`CLAUDE.md` と `.claude/rules/` は毎ターン全文が読まれるので、**毎回守らないと事故る規則だけ**を置く。
それ以外（手順・理由・事例・表・一覧）はここへ置き、規則からは 1 行で指す。

## ディレクトリ構成

```
docs/playbooks/
├── README.md                   # この目次
└── devlog-writing.md           # devlog の書き方
```

## 何をどこに書くか

| 内容 | 置き場 |
|------|--------|
| 毎回守らないと事故る規則（やる・やらない） | `CLAUDE.md` / `.claude/rules/`（1 ファイル 3000B まで） |
| やり方の手順・判断の理由・失敗事例・対応表 | `docs/playbooks/<トピック>.md`（ここ） |
| 初見の人が最初に知りたいこと | `README.md` |

予算は `tests/test_claude_md_budget.py` が測る（超えると落ちる）。落ちたら、超えた分をここへ移す。

## 書き方

- 1 ファイル 1 トピック。規則側の 1 行から開けること（`詳しくは docs/playbooks/<名前>.md`）
- 規則側に要約を写さない（正本が 2 つになり、片方だけ直ってずれる）
- 作ったら「一覧」の表と上の「ディレクトリ構成」のツリーの両方へ 1 行足す（`test_doc_tree.py` は実ファイルとツリーの食い違いで落ちる）
